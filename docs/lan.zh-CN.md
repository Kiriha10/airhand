# 独立局域网连接

Windows 被控端与安卓、iPhone/iPad 控制端可以在局域网内直接连接。中转服务器不可达、断线或重新上线时，局域网会话仍可建立和继续运行。

## 使用

1. 更新 Windows 安装版与相应移动端，保持 Windows 上 Airhand 运行。
2. 右击 Windows 托盘图标，打开 **局域网连接（无需中转）**，点击当前网卡的地址以复制，例如 `192.168.1.20:4434`。
3. 手机或 iPad 连接互通的同一局域网，在 Airhand 的“远程”页选择 **局域网连接**，输入这个地址后连接。
4. 首次连接按提示输入 Windows 托盘里的 **配对码**。iPad 询问本地网络权限时选择允许。

连上后设备会保存本地地址和已确认的身份，以后点击“我的设备”里的对应设备即可。不同地址书写方式（如省略默认端口）会复用已保存的设备身份。局域网重连凭证与中转重连凭证分开保存。

## 连接条件

局域网监听使用 **UDP 4434**，可省略地址里的默认端口。Windows 安装包为“专用”网络上的本地子网添加入站规则；请将当前可信局域网设为专用网络。仅为当前用户安装时，Windows 的防火墙提示需要允许专用网络。

两端需要互通。访客 Wi-Fi、AP 隔离、不同 VLAN 的访问限制会影响连接。被控端关机、睡眠或 Airhand 退出后需恢复运行才能连接。

Windows 显示中转服务器“无法连接”时，托盘中的局域网地址和配对码仍可使用。此功能从本地地址发起连接，不需要公网服务器上的在线登记。
